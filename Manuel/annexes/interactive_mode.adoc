
[[interactive-mode]]
=== Mode interactif ===

Le __mode interactif__ de la commande `songbook` permet de ne pas avoir à taper `songbook` chaque fois qu'on veut jouer une commande. Il permet aussi de fixer un contexte (un carnet et une chanson) qui rendront très confortable le travail sur le carnet et les chansons.

On entre en mode interactif avec :

----
songbook -i
----

À partir de là, on peut faire simplement :

----
🎸> build "titre chanson"
----

Pour focaliser toutes les commandes suivantes sur une chanson en particulier, celle qu'on travaille par exemple : 

----
🎸> use song "chanson court"
----

… ou sur un carnet :

----
🎸> user songbook "mon carnet"
# ou 
🎸> user sb "mon carnet"
----

Noter que le titre à rentre ici peut être tout à fait <<approximatif>>.
