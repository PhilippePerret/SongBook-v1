=== Production du schéma du diags ===

Utiliser la commande : 

----
diag
----

[[diag-svg-producer]]
==== Production de l'image SVG du diagramme ====

Pour produire une image à partir d'un schéma, utiliser la commande : 

----
songbook build diag "schéma"
----

Par exemple :

todo: exemple

… qui produira :

todo: exemple image

==== Actualisation des diags ====

Si vous avez ajouté des diags dans l'application, il peut être nécessaire d'actualiser les fichiers SVG et surtout le fichier HTML présentant tous les diags et permettant d'en choisir. Pour ce faire, utiliser la commande : 

----
songbook update diags
----

Ou simplement `update diags` en mode interactif.
