[[song-assistant]]
=== Assistant de création de la chanson ===

Pour créer rapidement une chanson, on peut utiliser l'assistant. Dans un Terminal (ouvert n'importe où) jouer la commande : 

----
songbook create song
----

Ou, si vous connaissez déjà le titre et l'interprète : 

----
songbook create song "Le titre de la chanson"

songbook create song "le titre de la chanson" "le chanteur"
----

En mode interactif, c'est encore plus facile de travailler sur une chanson :

L'assistant vous assiste ensuite pour obtenir le maximum d'informations sur la chanson et créer les fichiers nécessaires.

Il existe aussi un <<song-chords-assistant, assistant très pratique>> pour placer les accords. Cet outil permet de placer les accords très facilement et rapidement, avec beaucoup de confort.

----
songbook -i
🎸> use song "titre chanson"
# Tout le reste concernera la chanson
open # ouvre ce qu'on veut
build # construit la chanson
tab assistant # ouvrir l'assistant tablatures
build diags # construit les diagrammes 
# etc.
----
