[[song-assistant]]
=== Assistant de création de la chanson ===

Pour créer rapidement une chanson, on peut utiliser l'assistant. Dans un Terminal (ouvert n'importe où) jouer la commande : 

----
songbook create song
----

Ou, si vous connaissez déjà le titre et l'interprète : 

----
songbook create song "Le titre de la chanson"

songbook create song "le titre de la chanson" "le chanteur"
----

Sinon, ils vous seront demandés au fur et à mesure, comme toutes les informations suivantes.

NOTE: Si c'est votre première chanson, **__SongBook__** vous demandera aussi de définir le dossier où devront être créées toutes les chansons.
