=== Fichier infos du carnet ===

Toutes les informations concernant le carnet se rangent dans le fichier `.infos` à la racine du carnet de chant ou de la chanson, par exemple :

----
Carnet-de-chant-Peter-Gabriel
  |— carnet.infos
----

Ce fichier définit aussi bien les __métadonnées__ de la chanson (titre, compositeur ou compositrice, année, etc.) que les options qui font régirent la construction du fichier PDF. Les seules informations impératives sont l'identifiant (`id`) et le titre du carnet (`title`).

[[infos-full-list]]
==== Liste complète des infos (hors options) ====

Vous trouverez ci-dessous une liste complète des informations possibles, avec leur desccription.
----
title: Le titre du carnet (couverture)
id: Une identifiant éventuel
format: Largeur et hauteur du carnet (A5 en paysage par défaut)
layout: le format par défaut d'affichage des chansons (regular-B par défaut)
subtitle: Le sous-titre
editor: 
  name: Nom de l'éditeur
  logo: path du logo

cover:
  image: path/to/image
  binding: true|false # pour dessin marqué de la reliure

front_matter:
  half_title_page: false # faux-titre
  title_page: true
  # Définition des tables des matières
  table_of_contents:
    per_song: true
    per_performer: true
    per_composer: false
    per_author: false
  forword: false # Avant propos (false, ou le fichier)
  preface: preface.md # préface
  acknowledgments: false # (false ou le fichier remerciements)
copyright: @2026 Icare éditions Tous droits réservés

credits:
  book_designer: Philippe Perret
  typesetter: Philippe Perret
  proofreader: Marion Michel
  programming: Claude
  
# Options
options:
  # Voir les options du carnet  
  
----
