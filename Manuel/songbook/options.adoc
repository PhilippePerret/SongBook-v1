[[options, options]]
=== Options ===

On peut définir dans le fichier `infos` (`inf`) toutes les options gérant la fabrication des carnets ou des chansons.

NOTE: Noter que s'il y des options réglées pour le carnet en construction et des options réglées pour la chanson la précédence se fait en fonction de la nature de l'option, sauf dans le cas où l'option `todo: à déterminer` est à `true`.

==== Options générales ====

[cols="2,6,3,1,1", options="header"]
|====
| Prop. | Description 
| Valeurs | Opt. | Pr.

| `sensitivity` 
| Sensibilité aux erreurs, la façon de les gérer.
| `high`, [`mid`], `low` | `-v` | Carnet

|====

// Les valeurs explicitées

.3+| `sensitivity`    | `high`  | Le programme s'arrête à la première erreur et la signale.

                      | `low`   | Aucune interruption, les erreurs sont logguées silencieusement.

[[option-diags]]
===== Options pour les diags =====

----
diags:
  # Pour limiter les diags à une liste d'accords, par exemple seulement
  # les accords compliqués ou propres à la chanson
  list: [Am7, C, Dd7M]
  # Position dans les pages de chanson
  # [Int] : à l'intérieur, donc côté reliure du carnet.
  # Ext   : à l'extérieur, donc à l'opposé de la reliure.
  # Left  : dans une colonne toujours à gauche des paroles.
  # Right : dans une colonne toujours à droite des paroles.
  # Top   : en haut de la page.
  # Bot   : en bas de la page
  # Front : tous les diagrammes avant les paroles en 1^re^ page.
  # End   : tous les diagrammes après les paroles en dernière page.
  position: Left
  
  # Alignement des diags dans leur container (colonne ou rangée)
  # Valeurs possibles en fonction du contenant :
  # Ext/Int/Left/Right : [Center], Top, Bot, Justify
  # Top/Bot/Front/End  : [Center], Left, Right, Justify
  align: Center
  
  # Échelle (zoom) des diagrammes par rapport à la valeur normale
  # C'est une proportion par rapport à 1 (valeur normale).
  # Cette valeur ne s'applique pas si `size` est défini.
  scale: 1.5
  
  # On peut aussi fixer explicitement la taille des diagrammes.
  # Noter que si diags_shrink est true, cette taille pourra être
  # modifiée pour des raisons esthétiques.
  # La valeur a la forme largeur x hauteur. Si une valeur n'est pas
  # définie, elle sera calculée automatiquement par rapport à l'autre
  # "120 x" signifie : "largeur de 120 points et hauteur automatique"
  size: 120 x 
  
----



==== Placement des diags ====

Dans le <<infos-file>>, c'est le paramètre principal `diags` qui peut contenir les propriétés suivantes :

----
diags:
  list: [liste des accords à traiter]
  position: Top
  scale: 100
----

==== Tablatures et partitions ====

----
tablas:
  position: Under
  
----

[[songbook-options, options du carnet]]
==== Options du carnet ====

Ces options sont à définir (si changement par rapport au comportement par défaut) dans le fichier `infos` (ou `inf`) du carnet, donc à la racine de son dossier.

Elles se mettent dans la section **`options:`**

----
# Dans .infos/.inf

options:
  # Les options ici
----

[cols="1,3,3", options="header"]
|====
| Option 
| Description 
| Valeurs

| `show_specs`
| Pour une version de test d'impression, on peut mettre cette option à `true`, elle affichera les polices, tailles, etc. pour tout le carnet et les chansons en particulier.
| Défaut : `false`

| `printer`
| Imprimeur, le cas échéant.
| `Amazon`, `KDP`, `Lulu` etc.

| `tdm_position` 
| Position de la table des matières, en début (`front`) ou fin (`end`) du carnet.
| Défaut : `end`

| `build_unknown_song`
| Détermine si le dossier d'une chanson est créé si la chanson n'est pas trouvée (par son titre dans la table des matières).
| Défaut : `true` (oui, le dossier est créé)

| `text_column_guter`
| Détermine la largeur de gouttière par défaut, pour les textes à phrases longues.
| Défaut : `1cm`

| `text_font`
| Fonte pour les textes hors paroles/lyrics
| Défaut : `Times`

|====

[[songbook-layout-options, options de mise en page]]
==== Options de mise en page ====

__Note : ces options peuvent également être définies dans un fichier `.layout`/`.lay`.__

[cols="1,3,3", options="header"]
|====
| Caractéristique | Description | Valeurs

| `title_band` 
| Titre en bandeau ou pas.
| `true` = titre mis en bandeau

| `scores_title_size`
| Taille de la police pour les titres de partitions et de tablatures (avec unité)
| `12pt`

| `scores_title_bold`
| Les titres seront mis en gras si la propriété est `true`.
| [`false`] `true`

| `tabs_measures_per_page`
| Définit explicitement le nombre de mesures de tablature dans la page
| `6` (priorité aux carnets)

| `tabs_system_spacing`
| Définit l'espace entre deux systèmes de tablature.
| `12pt`

| `lyrics_flux`
| Définit le flux, l'enchainement des strophes, couplets, refrains et autres paroles.
| `side` (pour "side by side", "côte à côte") ou `vertical` (pour "stacked vertically" ou "l'un au-dessous de l'autre") ou `free` (pour "free positioning", aucune contrainte).

| `diags_position` 
| Position des diagrammes d'accords, par défaut, dans la page
| Cf. les <<position-values>>.

| `diags_size`
| Dimensions des diags lorsque cette dimension doit être fixe et non touchée.
| `auto`, `Nptx` (largeur de N points), `xNpt` (hauteur de N points), `NptxMpt` (largeur de N points et hauteur de M points) 

| `intro_align`
| Alignement d'un bloc désigné par "intro"
| Défaut : `left`

|====
