Doutes relevés en comparant le Manuel (Manuel/*.adoc) au code réel — RIEN testé

COMMANDES DOCUMENTÉES MAIS INTROUVABLES DANS lib/cli.rb
- `songbook list songs` (+ gabarit de sortie personnalisé) — aucun case "list"
- `songbook manual` / `songbook manuel` [sujet] — aucun case "manual"/"manuel"
- `songbook create songbook` / `create sb` — seul "create song" existe
- `songbook cover dims` / `cover modele-idml` / `cover modele-pdf` — aucun case
  "cover" ; lib/idml_cover_builder.rb existe mais n'est appelé nulle part
- `songbook build diag "<schéma>"` — répété dans 4 pages du Manuel, jamais câblé
- `songbook build tab` / `build tabs "titre"` — le vrai point d'entrée est
  `songbook tablator assistant` / `tab assistant`

AUTRES ÉCARTS DOC/CODE
- song/chords.adoc : quasi-copie de song/diags.adoc (copier-coller), ne documente
  pas vraiment l'outil d'accords (déjà couvert par tools/add_chords.adoc)
- song/lyrics.adoc "Riffs" (`/riff nom: ...`) : la syntaxe (espace dans le nom)
  ne peut pas matcher CHORD_RE ; aucun code de gestion des riffs trouvé

  est lue (font-family/font-size/font-style/font : jamais consommées)
- user_files/config.adoc : tout le bloc OPTIONS (`sensitivity`, `mode`,
  `labels_in_title_band`, `keep_order`, `shrink_diag`, `shrink_tabla`,
  `shrink_score`) : zéro référence trouvée dans le code

  `title: simple` (le code produit "inline", pas "simple") ; `infos: under|
